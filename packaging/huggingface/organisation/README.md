# Phonlet AI

On-device speech for edge devices.

## Phonlet Wake

Wake-word detection for any phrase you can type. One English model of about 1 MB listens for
several phrases at once, offline, with a sensitivity for each. A new phrase is made from text in
seconds: no recordings, no training run, no cloud. About 1.05 MB of memory while listening, 0.7%
of one laptop core, 19% of one ESP32-S3 core.

- **[Try it in your browser](https://huggingface.co/spaces/phonletai/wake)**: type a phrase and
  hear it detected live
- **[The `en-1` model](https://huggingface.co/phonletai/wake-en-1)**
- **[Source, SDKs and downloads](https://github.com/phonlet-ai/wake)**: Python, Node.js, the
  browser, C / C++, Java, Android, .NET and ESP32-S3
- **[Docs](https://phonletai.com/docs/)** and
  **[instructions for AI coding agents](https://phonletai.com/agents.md)**
