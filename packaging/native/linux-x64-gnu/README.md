# Wake native add-on for Linux x64

The Node-API v8 addon for `@phonlet-ai/wake-node` 0.1.0. The engine is compiled into this addon; no build scripts or runtime downloads are used. `build.json` records the source/build identity. It is qualified on the Linux x64 glibc/libstdc++ host recorded in `build.json`; older glibc baselines and other platforms are not yet qualified.
